# portfolio

Персональный портфолио-сайт: тёмная тема, адаптив под ПК и мобильные, чистый CSS.

## 🚀 Демо

https://твой-username.github.io/portfolio/

> Замени `твой-username` на свой GitHub-логин после включения GitHub Pages.

## ✨ Возможности

- Тёмная тема с мятным акцентом (`#5EEAD4`) и фиолетовым дополнением
- Полностью адаптивная вёрстка — от 380px до 1400px+
- Карусель фото в hero-секции (стрелки, точки, свайп)
- Прогресс-бар скролла в навбаре
- Анимированное мобильное меню с задержками появления ссылок
- Появление секций при скролле (`fade-in`, `reveal`)
- Семантическая разметка
- Доступность: `focus-visible`, `prefers-reduced-motion`, контрастные цвета
- CSS-переменные для быстрой смены темы
- `clamp()` для плавной типографики

## 🛠️ Стек

- **HTML5** — семантическая разметка
- **CSS3** — Grid, Flexbox, CSS-переменные, `clamp()`, `aspect-ratio`, `backdrop-filter`
- **Vanilla JavaScript** — карусель, мобильное меню, прогресс-бар, IntersectionObserver

Без фреймворков, без сборки — открывается прямо в браузере.

## 🖥️ Локальный запуск

Просто открой `index.html` в браузере.

Или через Live Server в VS Code:

1. Установи расширение **Live Server**
2. Правый клик по `index.html` → **Open with Live Server**

Или через Python:

```bash
python -m http.server 8000
```

Затем открой http://localhost:8000

## 🌐 Деплой на GitHub Pages

1. Запушь проект в репозиторий на GitHub
2. Зайди в **Settings → Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` → папка `/ (root)`
5. Нажми **Save**
6. Через 1–2 минуты сайт будет доступен по адресу:

```
https://твой-username.github.io/portfolio/
```

## 🎨 Кастомизация

Все ключевые значения вынесены в `:root` в начале `css/style.css`:

```css
:root {
  --bg: #0B0A09;              /* фон */
  --accent: #5EEAD4;          /* акцент */
  --accent-2: #A78BFA;        /* второй акцент */
  --text: #F5F3EF;            /* основной текст */
  --maxw: 1200px;             /* ширина контейнера */
  --radius: 20px;             /* радиус скругления */
  /* ... */
}
```

Чтобы сменить тему — достаточно поменять несколько переменных.
